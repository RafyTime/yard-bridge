# 01: Improve the PWA experience

Type: task
Status: needs-triage

Draft reminder. Scope and acceptance criteria will be fleshed out later.

## Ideas to cover

- Show an update-available prompt with an explicit reload action, without interrupting a Game automatically.
- Handle updates across multiple open tabs so players do not need to close every tab manually.
- Offer platform-appropriate installation prompts for Android and other supported devices and browsers.
- Provide clear iOS installation guidance when a native install prompt is unavailable.
- Avoid repeated prompts after dismissal and unnecessary install prompts for an already installed app.
- Review other PWA usability gaps during planning, including offline and connection feedback.
