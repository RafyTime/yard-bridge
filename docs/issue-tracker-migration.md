# Issue tracker migration

Specs, tasks, and planning maps moved to [GitHub Issues](https://github.com/RafyTime/yard-bridge/issues).
GitHub is authoritative for their status and discussion. Supporting stack research
lives in [research/yard-bridge-stack.md](research/yard-bridge-stack.md).

Original files and their Git history remain available at
[the pre-migration commit](https://github.com/RafyTime/yard-bridge/tree/8b6f953b868138f43036fc77d43de8b6f52aa676/docs/.work).
Original discussion and answers were preserved in issue bodies, without assigning
new authors or timestamps to historical comments. Relative links now point to
migrated issues or repository documents. Original status lines are historical.
Completed task records imported as closed issues. Effort summaries with all tasks
resolved imported as closed even where their original status was stale.
